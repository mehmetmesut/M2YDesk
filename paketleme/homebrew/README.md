# M2Y Software Homebrew Tap

Install [M2YDesk](https://desk.mehmetmesut.com) on macOS (Apple Silicon) with Homebrew:

```bash
brew install --cask mehmetmesut/m2y/m2ydesk
```

Update:

```bash
brew upgrade --cask m2ydesk
```

M2YDesk is a remote desktop and remote support client based on the open-source
[RustDesk](https://github.com/rustdesk/rustdesk) project (AGPL-3.0).
Source code: https://github.com/mehmetmesut/M2YDesk
